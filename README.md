## FitLog Workout Library & Planner

Discover your next workout, build today's plan, and track your progress in one place.

FitLog is a responsive fitness web application. Its dark interface and lime-green accents make it easy to browse exercises, explore workout details, and organize a daily routine.


## Technologies Used

1. **Next.js** 
2. **React** 
3. **Tailwind CSS v4** 
4. **lucide-react** 
5. **react-hot-toast** 
6. **Fontsource** 

## Key Features

1. **Workout library:** Browse workout cards populated from the FitLog API.
2. **Workout details:** Open a dedicated page for each exercise to see its information and statistics.
3. **Today's plan:** Add workouts to a personal daily exercise list.
4. **Save for later:** Keep workouts in a separate Saved tab for future reference during the session.
5. **Completion tracking:** Mark planned workouts as done.
6. **Plan management:** Remove exercises from today's plan or the saved list.
7. **Plan summary:** View the number of planned exercises, total duration, and total API-provided calorie estimates.
8. **Sorting:** Sort plan and saved workouts by duration, calories, or rating.
9. **Responsive layout:** Browse the interface on mobile, tablet, and desktop screens.
10. **Action notifications:** Receive toast feedback when adding, saving, removing, or completing workouts.
